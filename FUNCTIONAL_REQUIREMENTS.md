# Functional Requirements

## Identity and Access
- User authentication
- MFA-ready architecture
- Password policy
- Sessions and device management
- RBAC
- Branch/location restrictions
- Audit logging

## Employee Management
- Employee profile
- Employee number
- Department
- Designation
- Manager
- Location
- Employment status
- Joining/leaving dates
- Salary information
- Biometric identifiers/templates where required
- Documents

## Attendance
- Real-time transaction ingestion
- Duplicate detection
- Transaction validation
- Attendance calculation
- Manual correction workflow
- Approval workflow
- Shift assignment
- Cross-midnight shifts
- Flexible shifts
- Rotating shifts
- Holidays
- Grace periods
- Late/early rules
- Overtime
- Absence
- Missing punch handling

## Payroll
- Payroll periods
- Salary components
- Attendance inputs
- Overtime
- Leave impact
- Deductions
- Allowances
- Payroll approval
- Payroll locking
- Payslip generation
- Export/integration
- Country-specific rules as pluggable modules

## Device Management
- Vendor
- Model
- Device ID
- Serial number
- IP/domain
- Port
- Protocol
- Credentials
- Connectivity status
- Last communication
- Last transaction
- Synchronization status
- Firmware metadata
- Diagnostics

## Mobile
- GPS punch
- Geofence validation
- Attendance history
- Leave
- Overtime
- Corrections
- Approvals
- Notifications

## Access and Visitors
- Doors
- Access groups
- Schedules
- Access events
- Visitors
- Visits
- Hosts
- Check-in/out

## Reporting
All reports must support tenant-aware filtering, date ranges, branch/department/location filters, role restrictions, export, and auditability.
