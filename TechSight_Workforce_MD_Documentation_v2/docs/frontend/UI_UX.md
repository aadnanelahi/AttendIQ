# UI/UX Specification

## Design Principles
- Clean enterprise SaaS interface
- Fast dashboard interactions
- Responsive desktop/tablet/mobile web
- English/Arabic localization
- RTL support
- Accessible forms and tables
- Clear status indicators
- Explainable attendance/payroll states
