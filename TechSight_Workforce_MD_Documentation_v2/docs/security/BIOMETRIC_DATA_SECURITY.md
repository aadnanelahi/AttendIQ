# Biometric Data Security

## Principle
Biometric information is highly sensitive.

## Requirements
- Minimize collection
- Minimize retention
- Encrypt sensitive biometric data
- Restrict access by role and purpose
- Never expose biometric templates in ordinary reports
- Audit administrative access
- Secure device synchronization
- Support deletion/retention policies
- Separate biometric metadata from ordinary employee profile data where practical

Exact legal requirements must be validated for each deployment jurisdiction.
