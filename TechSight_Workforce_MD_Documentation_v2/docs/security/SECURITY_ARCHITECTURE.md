# Security Architecture

## Controls
- TLS
- Secure authentication
- RBAC
- Least privilege
- MFA-ready identity architecture
- Secure secrets management
- Encryption at rest
- Audit logging
- Rate limiting
- Input validation
- API authorization
- Secure file handling
- Security monitoring

## Biometric Security
Biometric templates and identifiers require special protection. Store only what is necessary, encrypt sensitive data, strictly restrict access, and avoid exposing biometric data through general APIs.

## AI Security
AI services must receive only authorized tenant data. Prompts, retrieved records, tool calls, and outputs must be subject to security controls and audit requirements.
