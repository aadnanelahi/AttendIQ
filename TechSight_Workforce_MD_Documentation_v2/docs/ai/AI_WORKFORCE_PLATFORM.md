# TechSight AI Workforce Platform

## Objective
Provide workforce intelligence without replacing deterministic attendance/payroll calculations.

## Features
- Natural-language workforce queries
- Attendance summaries
- Absence analysis
- Overtime analysis
- Late-arrival trends
- Anomaly detection
- Workforce insights
- Forecasting
- Management report generation

## Safety
AI is advisory unless a workflow explicitly requires human approval.

AI must never bypass RBAC, tenant isolation, payroll controls, or audit requirements.

Deterministic payroll and attendance calculations remain authoritative.
