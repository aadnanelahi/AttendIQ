# Device Testing

## Test Matrix
For every supported vendor/model:
- Registration
- Authentication
- Push transaction
- Pull transaction where supported
- Duplicate event
- Offline device
- Network recovery
- User synchronization
- Template synchronization where supported
- Time synchronization
- Device restart
- Invalid payload
- Credential failure
- Large transaction backlog

## Certification
A vendor adapter should not be considered production-ready until it passes the applicable device test matrix.
