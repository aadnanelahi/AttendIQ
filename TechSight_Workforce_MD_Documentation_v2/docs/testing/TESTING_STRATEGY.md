# Testing Strategy

## Required Testing
- Unit tests
- Integration tests
- API tests
- End-to-end tests
- Device adapter tests
- Attendance calculation tests
- Payroll calculation tests
- Security tests
- Performance tests
- Mobile tests

## Critical Rule
Attendance and payroll rules require extensive edge-case testing, especially overnight shifts, missing punches, duplicate transactions, holidays, leave, overtime, corrections, and timezone boundaries.
