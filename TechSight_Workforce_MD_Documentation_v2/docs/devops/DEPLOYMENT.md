# Deployment

## Cloud
Multi-tenant production deployment with scalable application services, managed database where appropriate, object storage, queues, monitoring, backups, and secure secrets.

## On-Premise
Installable customer environment containing the required application, database, device gateway, workers, and administration components.

## Hybrid
Cloud services can communicate with a customer-side device gateway where devices are inaccessible directly from the public cloud.

## Deployment Principle
Cloud and on-premise builds should share the same application/domain contracts wherever practical.
