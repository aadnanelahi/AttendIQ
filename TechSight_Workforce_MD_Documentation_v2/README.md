# TechSight Workforce Management

Modern SaaS Workforce Management Platform by TechSight Innovations FZE LLC.

## Vision
Build a modern, multi-tenant workforce platform for attendance, biometrics, scheduling, leave, payroll, access control, visitor management, mobile workforce, reporting, notifications, integrations, and AI-powered workforce intelligence.

## Deployment
- Cloud SaaS
- Customer-managed on-premise deployment
- Hybrid device connectivity

## Languages
- English
- Arabic

## Device Strategy
Vendor-neutral architecture. Initial integrations may include ZKTeco, with additional biometric/access-control vendors supported through adapters.

## Core Principles
Security-first, API-first, multi-tenant, auditable, scalable, real-time, modular, and AI-ready.
