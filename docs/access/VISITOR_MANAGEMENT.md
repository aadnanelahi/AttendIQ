# Visitor Management

## Visitor
Store identity and visit information according to configured privacy requirements.

## Visit Lifecycle
Invited → Approved → Expected → Checked In → Checked Out → Closed.

## Features
- Host
- Visit purpose
- Schedule
- Approval
- Check-in/out
- Badge/reference
- Visitor history
- Notifications

Visitor data must be tenant-scoped and retention-controlled.
