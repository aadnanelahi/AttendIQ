# Access Control

## Scope
TechSight will support attendance plus access control as separate but integrated domains.

## Features
- Doors
- Controllers/devices
- Access groups
- Access schedules
- Employee access assignments
- Access events
- Access exceptions
- Access reporting

## Separation
An employee's attendance status must not automatically imply door authorization unless an explicit policy is configured.

## Vendor Neutrality
Access devices use the same adapter architecture as biometric attendance devices.
