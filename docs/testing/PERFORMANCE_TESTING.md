# Performance Testing

## Scenarios
- Burst of device transactions
- Large employee import
- Large attendance report
- Monthly payroll calculation
- Concurrent mobile punches
- Concurrent managers approving requests
- AI queries against large tenant datasets

## Measures
- API latency
- ingestion latency
- processing throughput
- queue delay
- database query time
- report generation time
- resource utilization

Performance targets must be established during the capacity-planning phase.
