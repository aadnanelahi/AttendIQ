# Role-Based Access Control

## Core Roles
- Platform Super Admin
- Tenant Owner
- Tenant Admin
- HR Admin
- Payroll Admin
- Branch Manager
- Department Manager
- Supervisor
- Employee
- Auditor
- Device Administrator
- Access Control Administrator

## Requirements
Permissions must be granular and support resource scope such as tenant, branch, department, location, or employee group.

Server-side authorization is mandatory.
