# API Specification

## Principles
- REST-first
- Versioned endpoints
- JSON representations
- Explicit authentication
- Tenant-aware authorization
- Idempotency for transactional operations
- Pagination
- Filtering
- Sorting
- Consistent errors
- Rate limiting
- OpenAPI documentation

## Major API Domains
- Authentication
- Tenants
- Organizations
- Employees
- Departments
- Locations
- Devices
- Attendance
- Shifts
- Rosters
- Leave
- Overtime
- Payroll
- Access
- Visitors
- Reports
- Notifications
- Integrations
- AI
- Audit
