# Scalability

## Scale Dimensions
- Tenants
- Employees
- Devices
- Transactions
- Reports
- Payroll runs
- Mobile traffic
- AI requests

## Strategies
- Stateless API services
- Horizontal workers
- Queue-based processing
- Database indexing
- Read optimization
- Caching
- Partition/archive strategy for high-volume event data
- Asynchronous reports
- Independent device gateway scaling

## Hot Paths
Device ingestion and attendance queries require particular attention because they can generate large volumes of time-series-like data.
